### class PopulationManager

管理人口总数、生育分配、脱水库存。所有参数优先从 `config["population"]` 读取，缺失时使用硬编码默认值。

**关键属性**:
- `total: int` — 活跃人口
- `breeders: int` — 生育人口
- `stored_population: int` — 脱水库存中的人口
- `storage_capacity: int` — 总库存容量（由EntityManager每帧重算）
- `automation_multiplier: float` — 自动化倍率(默认1.0，科技后由config["research"]["automation_multiplier"]决定)
- `food_per_person_per_day: float` — 从config["population"]读取(默认0.1)
- `_starvation_threshold: float` — 饥荒阈值(默认0.5)
- `_starvation_rate: float` — 饥荒减员速率(默认0.01)
- `_dehydrate_food_rate: float` — 脱水时食物消耗倍率(默认0.2)

| 方法 | 参数 | 返回值 | 功能 | 调用方 |
|------|------|--------|------|--------|
| `__init__(initial_population, config)` | 初始人口/配置字典 | — | 从config["population"]读取参数，包括food_per_person_per_day, base_growth_per_breeder, starvation_threshold等 | EntityManager |
| `get_idle(total_building_workers)` | 建筑总工人数 | int | 活跃人口-生育-建筑工人 | EntityManager.get_idle_population |
| `get_storable_amount()` | — | int | storage_capacity - stored_population | DecisionManager._execute_policy(dehydrate) |
| `store_population(count)` | 存入人数 | (bool, str) | 检查容量→扣total→加stored | DecisionManager._execute_policy(dehydrate) |
| `retrieve_population(count)` | 取回人数 | (bool, str) | 检查stored→加total→扣stored | DecisionManager._execute_policy(rehydrate) |
| `update(dt_days, food_available, dehydrated)` | 天数/食物/是否脱水 | {food_consumed, growth} | 食物消耗(脱水×_dehydrate_food_rate)→饥荒减员→生育增长→自然增长 | EntityManager.update |
| `get_state()` | — | dict | 序列化(含stored_population, storage_capacity) | EntityManager.get_state |
| `load_state(data)` | 字典 | — | 反序列化(含向后兼容assignments→breeders) | EntityManager.load_state |

### class Building (dataclass)

**关键属性**:
- `id, name, building_type, zone_id` — 标识与位置
- `worker_capacity, assigned_workers` — 人力模型
- `per_worker_output: dict` — 每工人每日产出(资源→数量)
- `consumption: dict` — 建筑本身每日消耗
- `durability/max_durability` — 耐久度
- `build_time/build_progress/under_construction` — 建造系统
- `heat_resistance=60, cold_resistance=-80, radiation_resistance=5.0` — 环境抗性
- `storage_capacity: int = 0` — 库存容量(庇护所20, 深地100, 脱水仓100, 大型脱水仓500)
- `active, destroyed` — 状态

| 方法 | 参数 | 返回值 | 功能 | 调用方 |
|------|------|--------|------|--------|
| `get_output(automation_multiplier=1.0, zone_efficiency=1.0)` | 自动化倍率/区域效率 | dict{资源:数量} | 产出=workers×per_worker×耐久比×自动化×区域效率 | EntityManager._process_buildings, get_electricity_balance, GameSimulator._process_research_output |
| `get_consumption()` | — | dict | 建筑消耗(不依赖工人) | EntityManager._process_buildings, get_electricity_balance |
| `get_saturation()` | — | float 0~1 | assigned/capacity | GameSimulator._process_research_output |
| `take_damage(amount)` | 伤害量 | — | 耐久减少，归零则destroyed | apply_environment_damage |
| `repair(amount)` | 修复量 | — | 已摧毁不可修 | — |
| `apply_environment_damage(zone_temp, zone_radiation, dt, heat_coeff=0.02, cold_coeff=0.01, rad_coeff=0.03)` | 区域温/辐射/帧间隔/伤害系数 | — | 超 抗性→伤害(系数从config["damage_rates"]读取) | EntityManager.update |

| 值 | 说明 |
|---|------|

### 建筑决策定义 (config-driven)

建筑决策优先从 `config["buildings"]` 读取（17个建筑类型），缺失时使用 `_DEFAULT_BUILDINGS` 硬编码默认值。每个建筑的 resource_cost, worker_capacity, per_worker_output, consumption, build_time, storage_capacity 均可通过 config.yaml 覆盖。

**政策类(2)**（始终硬编码）: dehydrate(脱水入库), rehydrate(浸泡苏醒)

## 3. game/simulator.py — 游戏模拟器

### class GameSimulator

**关键属性**:
- `environment: ThreeBodySimulation` — 三体运动
- `entities: EntityManager` — 实体/资源/人口
- `tech_tree: TechTree` — 科技
- `decision_manager: DecisionManager` — 决策
- `planet_zones: PlanetZoneManager` — 区域
- `research_output_rate: Dict[str, float]` — 三种科研点每日产出速率(EMA平滑)
- `_research_config: dict` — 从config["research"]读取(人口除数/建筑产出/脱水倍率/EMA系数/自动化倍率)
- `_storage_damage_config: dict` — 从config["storage_damage"]读取(温度/辐射阈值及损耗率)
- `_time_scale_min/max: float` — 从config["simulation"]读取(默认0.1/10.0)
- `time, paused, game_over, universe_name`

| 方法 | 参数 | 返回值 | 功能 | 调用方 |
|------|------|--------|------|--------|
| `__init__(config)` | 配置 | — | 初始化五大子系统(TechTree/DecisionManager传入config)+温度校准，提取research/storage_damage/time_scale配置 | main.py, start_game_menu |
| `reset(config)` | 配置 | — | 重置(保留universe_name)，重新提取配置 | — |
| `update(dt)` | 帧间隔 | — | 三体运动→区域环境→实体更新→研究产出→脱水损耗→冷却→计时 | main.py主循环 |
| `_process_research_output(game_days_dt)` | 游戏天数 | — | 人口基础科研+研究院+实验室+科学院(产出率从config["research"]读取); 更新research_output_rate EMA; 检测自动化科技完成 | update |
| `_process_storage_damage(game_days_dt)` | 游戏天数 | — | 脱水时:库存设施按区域环境损耗(阈值和损耗率从config["storage_damage"]读取); 无设施全灭; 暴露人口额外衰减 | update |
| `get_state()` | — | dict | 完整状态(含research_output_rate) | UI只读渲染 |
| `to_dict()` | — | dict | 存档序列化 | SaveManager |
| `from_dict(data)` | 字典 | — | 存档反序列化(含旧版兼容) | SaveManager |
| `toggle_pause()` | — | — | 切换暂停 | UI |
| `set_time_scale(scale)` | 倍率 | — | 设置_time_scale_min~_time_scale_max(从config["simulation"]读取) | UI |
| `_init_zone_temperatures()` | — | — | 两轮校准:先用scale=500测均温→反推light_to_temp_scale使均温≈20℃→校准light_norm_divisor→重新初始化 | __init__, reset |

## 9. UI 层概要

### ui/screen_manager.py

- **ScreenType(Enum)**: 10种界面类型
- **Screen(基类)**: load_fonts, on_enter/exit, update, handle_event, render, setup_ui
- **ScreenManager(单例)**: switch_to, go_back, clear_stack_and_switch, register_screen, global_state

### ui/initial_menu.py

- **StarBackground**: 动态星空(闪烁+左移)
- **MenuButton**: 通用按钮(悬浮动画+回调, selected状态高亮显示)
- **InitialMenu**: 开始游戏/设置/退出

### ui/start_game_menu.py

- **TextInput**: 文本输入框(含IME支持)
- **StartGameMenu**: 4子状态(主菜单/命名/宇宙列表/存档列表)

### ui/settings_screen.py

- **GameSettings(dataclass)**: 游戏设置(游戏/显示/音频/控制)
- **SettingSlider**: 滑块组件(拖拽+回调, time_scale范围0.1~10.0)
- **SettingCheckbox**: 复选框组件
- **SettingsScreen**: 4标签页设置, on_apply设置_settings_apply_pending标志

### ui/game_menu.py

- **GameMenu**: 暂停菜单(继续/设置/保存/返回主菜单)+保存面板

### ui/main_screen.py

- **MainScreen**: 2D主界面
  - 工具栏(10按钮): 菜单/暂停/1x/2x/3x/5x(速度切换,高亮选中)/科技树/政策/区域/星图
  - 3面板: 资源总览 / 文明与状态(含科研产出速率+库存人口) / 环境监控
  - 键盘快捷键: 空格暂停, +/-调速, 1/2/3/5直接切速
  - 速度指示器: 速度不为1x时在游戏天数旁显示当前倍率

### ui/starmap_view.py

- **StarmapView**: 3D星图(自由视角/行星锁定+Compass+HUD)

### ui/tech_tree_screen.py

- **TechTreeScreen**: 科技树可视化
  - 贝塞尔连线 + 4色节点(锁定/可研发/解锁/研究中)
  - 悬浮Tooltip + 右上角科技点(含+X/天产出速率) + 研究进度条

### ui/decision_screen.py

- **DecisionScreen**: 政策决策(仅脱水/浸泡)+库存信息显示

### ui/zone_view_screen.py

- **ZoneViewScreen**: 区域浏览
  - 左: 12×6热力图(温度/辐射/光照) + 经纬标签 + 建筑数量标记
  - 右: 全球概览(含库存人口) + 区域详情(含工作效率+库存人口+建筑效率/产出)
  - 建造菜单(滚动列表)

### render/scene.py

- **StarField**: 3D星空粒子
- **SceneRenderer**: 3D渲染(恒星渐变/行星明暗/轨迹/行星网格)
  - `_draw_planet_grid`: 经纬网格+自转

### render/camera.py

- **Camera**: Y-then-X旋转透视投影
  - 自由模式: rotate/move/zoom
  - 锁定模式: orbit_rotate/orbit_zoom/update_orbit
  - `world_to_screen()`: 3D→2D投影
  - `check_collision()`: 星体碰撞检测

### render/ui.py

- **get_font(size)**: 跨平台中文字体加载
- **UIElement/Button/Label/Panel/Compass**: UI组件
- **UIManager**: UI元素容器
- **create_hud()**: 创建顶部环境面板+罗盘
- **update_hud()**: 更新HUD数据
