## 1. scripts/simulation/three_body.gd — 三体运动模拟

`class_name ThreeBodySimulation extends RefCounted`

### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `G` | 1.0 | 简化引力常数 |
| `TRAIL_LENGTH` | 200 | 每颗星的轨迹队列长度 |

### 属性

| 名称 | 类型 | 说明 |
|---|---|---|
| `stars` | Array[StarData] | 4 天体（3 恒星 + 1 行星） |
| `time_scale` | float | 模拟时间倍率（默认 1.0） |

### class StarData

| 字段 | 类型 | 说明 |
|---|---|---|
| `mass` | float | 质量（恒星 500~1100，行星 1.0） |
| `position` | Vector3 | 当前 3D 坐标 |
| `velocity` | Vector3 | 当前速度 |
| `color` | Color | 显示颜色 |
| `radius` | float | 显示半径（缩放 0.5 后使用） |
| `is_planet` | bool | 是否为行星 |
| `trail` | Array[Vector3] | 轨迹队列（FIFO，max 200） |

### 方法

| 方法 | 参数 | 返回值 | 功能 | 调用方 |
|---|---|---|---|---|
| `_init()` | — | — | 调用 `_initialize_stars()` 生成初始配置 | GameState.new_game, GameState.from_dict |
| `_initialize_stars()` | — | — | 随机生成层级稳定 4 天体：内双星（互绕）+ 外第三星（绕双星质心）+ 行星（绕双星） | `_init()` |
| `compute_forces_for_state(positions)` | Array[Vector3] | Array[Vector3] | 遍历所有星对计算引力合力 = `G×mi×mj×r / dist^3`（用于 RK4 四步） | `update()` ×4 |
| `update(dt)` | float | void | RK4 四阶积分 + 1e-5 随机微扰 + 轨迹 push/pop | GameState.update |
| `get_environment_params()` | — | Dictionary | 返回 {light_intensity, heat_level, temperature, radiation, stability} — 光照=Σ mass×10/(dist²+100)/8，温度=-273.15+光照×7000，辐射=Σ mass×200/dist^2.5，稳定性=1/(1+accel/0.1) | GameState.update, PlanetZoneManager |
| `_compute_stability(planet)` | StarData | float(0~1) | 行星所受合力加速度的倒数映射 | `get_environment_params()` |
| `get_stars_data()` | — | Array[Dictionary] | 每星 {position, mass, is_planet} | GameState.update, PlanetZoneManager |
| `get_planet_position()` | — | Vector3 | 行星坐标（遍历找 is_planet==true） | GameState.update |

## 2. scripts/simulation/planet_zones.gd — 行星区域系统

`class_name PlanetZoneManager extends RefCounted`

### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `LATITUDE_DIVISIONS` | 6 | 纬度分 6 行（每行 30°） |
| `LONGITUDE_DIVISIONS` | 12 | 经度分 12 列（每列 30°） |
| `TOTAL_ZONES` | 72 | 总区域数 |
| `TERRAIN_TYPES` | ["平原","高原","山地","峡谷","盆地","丘陵"] | 6 种地形 |
| `TERRAIN_RESOURCE_TABLE` | dict{str: dict} | 地形→{iron, copper, rare_mineral, fertility, algae} 基础系数 |
| `TERRAIN_THERMAL_MODIFIER` | dict | 地形温度修正：平原 0 / 高原 -6 / 山地 -10 / 峡谷 -2 / 盆地 +3 / 丘陵 -3 |

### 属性

| 名称 | 类型 | 说明 |
|---|---|---|
| `zones` | Array[PlanetZone] | 72 个区域 |

| `diffusion_rate` | float | 大气扩散率（默认 0.15） |
| `dark_side_scatter` | float | 暗面散射因子（默认 0.25） |
| `light_to_temp_scale` | float | 光照→温度转换因子（默认 500，经 `_init_zone_temperatures` 校准） |
| `light_norm_divisor` | float | 光照归一化除数（默认 1.0，经校准） |

### class PlanetZone

| 字段 | 类型 | 说明 |

| `lat_bottom`, `lat_top`, `lon_left`, `lon_right` | float | 边界 |

| `radiation` | float | 当前辐射值 |

| `algae_density` | float | 藻类密度 |
| `building_ids` | Array[int] | 该区建筑 ID 列表 |
| `area_weight` | float | 面积权重（cos(lat)） |
| `get_work_efficiency()` | float | 委托静态方法 `_calc_work_efficiency(temperature)` |

### 方法

| 方法 | 参数 | 返回值 | 功能 | 调用方 |
|---|---|---|---|---|
| `_init(env_config)` | Dictionary | — | 读取 rotation_speed/thermal_inertia/diffusion_rate/dark_side_scatter → `_init_zones()` → `_build_neighbor_cache()` | GameState.new_game |
| `_init_zones()` | — | void | 6×12 循环：面积权重=cos(lat) → 随机地形 → 资源含 ±30% 浮动 | `_init()` |
| `_build_neighbor_cache()` | — | void | 每区 ≤4 邻居（左右经度 wrapi，上下纬度无环绕），存 `_neighbor_cache[zone_id] = [neighbor_ids]` | `_init()` |
| `_get_zone_normal(zone)` | PlanetZone | Vector3 | 球面经纬→笛卡尔单位法线（含自转 `rotation_angle` 偏移） | 区域环境计算 |
| `update(dt, time_scale, stars_data, planet_pos)` | float, float, Array, Vector3 | void | 自转角度更新 → `_collect_active_stars()` → `_compute_zone_environments()` | GameState.update |
| `initialize_temperatures(stars_data, planet_pos)` | Array, Vector3 | void | 设定目标温度（跳过热惯性）+ 10 轮扩散 | GameState._init_zone_temperatures |
| `_collect_active_stars(stars_data, planet_pos)` | Array, Vector3 | Array[Dictionary] | 排除行星 → 返回 [{direction, distance, mass}] | 区域环境计算 |
| `_compute_zone_environments(active_stars, dt)` | Array, float | void | 逐区光照（法线·星光方向 × 散射因子）+ 温度趋近（热惯性）+ 辐射 + 扩散 | `update()` |
| `_apply_diffusion(game_days)` | float | void | 每区温度向其邻居均温靠拢（factor = diffusion_rate × abs(dt), clamped 1.0） | `_compute_zone_environments()`, `initialize_temperatures()` |
| `get_zone(zone_id)` | int | PlanetZone or null | 按 ID 查找 | EntityManager, GameState, UI |
| `get_zone_at(lat, lon)` | float, float | PlanetZone or null | 按经纬度查找 | UI |
| `get_average_environment()` | — | {temperature, radiation, light_intensity} | 面积加权平均 | GameState 多处 |
| `get_zone_environment(zone_id)` | int | Dictionary | 完整区域数据（含建筑数、资源、效率） | UI |
| `get_all_zones_summary()` | — | Array[Dictionary] | 72 区简要数据（id, lat_i, lon_i, temp, rad, light, terrain, buildings, fertility, algae, deposits） | GameState.get_state, UI |
| `get_illuminated_zones()` | — | Array[int] | light > 0.05 的 zone_id 列表 | — |
| `add_building_to_zone(zone_id, building_id)` | int, int | bool | 追加到 zone.building_ids | DecisionManager._execute_construction |
| `remove_building_from_zone(zone_id, building_id)` | int, int | void | 从 building_ids 移除 | — |
| `get_state()` | — | Dictionary | 序列化：rotation_angle + light_to_temp_scale + light_norm_divisor + zones 列表 | GameState.to_dict |
| `load_state(data)` | Dictionary | void | 反序列化恢复 rotation_angle / 地形 / 温度 / 建筑 / 资源 | GameState.from_dict |

### 静态方法

| 方法 | 功能 |
|---|---|
| `_calc_work_efficiency(temperature)` → float | -10~40°C=1.0；<-80 或 >100°C=0.0；中间线性 |
