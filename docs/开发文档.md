## 项目概述

《三体文明》是一款基于刘慈欣《三体》世界观的三维星际经营模拟游戏。玩家需要在乱纪元中建立文明，发展科技，应对三体世界的不稳定环境。

### 技术栈
- **引擎**: Pygame 2.x（手写3D透视投影，无OpenGL）
- **语言**: Python 3.9+
- **数学**: NumPy（矩阵/向量运算）
- **配置**: YAML (pyyaml)
- **存档**: JSON

## 核心架构

### 更新主循环

```
main.py::run_game_loop()
  │
  ├── ScreenManager.update(dt)     → 当前界面.update()
  ├── GameSimulator.update(dt)     → 游戏逻辑推进
  │   ├── ThreeBodySimulation.update()     → RK4三体运动
  │   ├── PlanetZoneManager.update()       → 自转 + 逐区环境
  │   ├── EntityManager.update()           → 建筑伤害/建造/产出/人口
  │   ├── _process_research_output()       → 科技点产出
  │   ├── _process_storage_damage()        → 脱水库存损耗
  │   └── DecisionManager.update_cooldowns()
  └── ScreenManager.render(screen) → 当前界面.render()
```

### 模块依赖关系

```
GameSimulator ──→ ThreeBodySimulation (环境)
              ──→ EntityManager       (实体/资源/人口)
              ──→ TechTree            (科技)
              ──→ DecisionManager     (决策/政策)
              ──→ PlanetZoneManager   (区域)

DecisionManager ──→ Building (entities.py, 延迟导入)
                ──→ PopulationManager.store/retrieve (运行时参数)
TechTree ──→ EntityManager.consume_resource (运行时参数)
EntityManager ──→ PlanetZone.get_work_efficiency (运行时参数)

UI层 ──→ GameSimulator.get_state() (只读渲染)
      ──→ DecisionManager.execute_decision() (用户操作)
      ──→ TechTree.start_research() (用户操作)
      ──→ EntityManager.assign_worker_to_building() (用户操作)
      ──→ SaveManager.save_game/load_game (存档)
```

### 数据流：脱水/浸泡机制

```
用户点击"脱水"
  → DecisionScreen.on_decision("dehydrate")
    → DecisionManager.execute_decision("dehydrate", ...)
      → _execute_policy("dehydrate", entities)
        → PopulationManager.get_storable_amount()  ← 检查容量
        → PopulationManager.store_population(n)    ← 人口入库
        → CivilizationState = DEHYDRATED

每帧(脱水状态中):
  → EntityManager.update(dehydrated=True)
    → PopulationManager.update(dehydrated=True)    ← 食物消耗×0.2
    → _process_buildings(dehydrated=True)          ← 非关键建筑产出×0.1
  → _process_research_output()                     ← 科研产出×0.1
  → _process_storage_damage()                      ← 库存按区域环境损耗

用户点击"浸泡"
  → PopulationManager.retrieve_population(stored)  ← 人口苏醒
  → CivilizationState = NORMAL
```

## 关键系统概述

### 行星区域系统
- 72区域 (12经度 × 6纬度)，30°一格
- 每区域：法线方向 + 地形 + 温度/辐射/光照 + 资源禀赋 + 建筑列表
- 自转15°/天，热惯性 + 大气扩散
- 工作效率：-10~40℃=100%，<-80或>100℃=0%

### 科技点数体系
| 类型 | 产出来源 | UI显示位置 |
|------|---------|-----------|
| 基础科研 | 人口/500/天 + 研究院建筑 | 科技树右上角 + 主界面文明面板 |
| 应用科研 | 实验室建筑 | 同上 |
| 理论科研 | 科学院建筑 | 同上 |
- 所有科研建筑产出受区域工作效率影响
- 脱水时科研产出降为10%

### 建筑产出模型
```
产出 = min(assigned_workers, worker_capacity)
      × per_worker_output
      × (durability / max_durability)
      × automation_multiplier
      × zone_work_efficiency
      × power_ratio(电力不足时<1)
      × (脱水? 0.1 : 1.0)  [仅非关键建筑]
```

### 库存人口系统
- 库存容量由建筑提供：庇护所(+20)、深地庇护所(+100)、脱水仓(+100)、大型脱水仓(+500)
- 脱水时：尽可能多的人入库，剩余1%留维持，其余暴露
- 库存人口按所在区域环境损耗(极端温度0.5~5%/天，高辐射0.3~2.3%/天)
- 无活跃库存设施时库存人口全灭

### 政策系统
- 只有两个政策：**脱水**（人口入库，消耗-80%，产出-90%）和**浸泡**（人口苏醒，恢复正常）
- 脱水不再要求库存足够99%人口，能存多少存多少
