# 三体文明 Game

> 🚧 项目仍在开发中。当前版本已从 Python/Pygame 重构为 Godot 4 项目。

《三体文明》是一款以三体问题为核心的 3D 太空生存与文明经营模拟游戏。玩家需要在三颗恒星导致的极端环境中管理人口、资源、建筑、科技和政策，并尝试让文明穿越乱纪元。

## 当前功能

- 三体运动模拟：RK4 积分、轨迹记录、光照、温度、辐射、稳定性与天体碰撞终局。
- 开局场景规则：配置驱动的简单/普通/困难/极限/自定义难度、稳定星历与到期连续切换真实 N 体混沌。
- 文明观测预测：实际运行的天文观测站积累数据，轨道和危机信息按观测质量与能力逐级公开，不读取未来真实结果。
- 3D 星图：深空环境、分色粒子星空、恒星动态表面/日冕/光照、程序化行星海陆云层、渐隐轨迹、行星经纬网、行星锁定视角和分级轨道预测。
- 72 区域行星系统：12×6 经纬分区、自转、热惯性、温度扩散、地形和资源禀赋；当前尚无首都区、勘探队、跨区迁徙或区域物流。
- 区域建造：指定区域建造设施，查看施工进度、耐久、产出与消耗，并分配工人。
- 科技树原型：多层依赖、三种科研点、渐进研究、详情 Tooltip、缩放和拖拽浏览；下一代知识发现/传承系统已完成文档设计，尚未实现。
- 文明政策：全民脱水、浸泡复苏、大生育计划、配给制和工业强心剂。
- 实体经济：人口、食物、矿物、燃料、电力、建筑损伤与工作效率。
- JSON 存档：新宇宙自动生成初始存档，手动存档可命名；主菜单与暂停菜单复用同一个可选、可删除的分组存档浏览器，可完整恢复星体、科技、建筑、区域、人口和政策状态。
- 开发者工具：可绕过星图入口限制，并直接修改人口、资源、科研点或解锁全部科技，便于逐系统测试。
- 自适应界面：以 1920×1080 为设计基准，通过统一锚点、边距和缩放适配 1080p、2.5K 与更高常规分辨率。

## 运行要求

- Godot Engine 4.7 或更高版本（当前最低验证版本为 4.7）
- 支持 Forward Plus 渲染的图形环境
- Windows 或 Linux

项目不再需要 Python、Pygame 或 NumPy。

## 运行方式

### Godot 编辑器

1. 用 Godot 4.7 打开项目根目录中的 `project.godot`。
2. 点击“运行项目”或按 `F6/F5`。

### 命令行

```bash
godot --path .
```

如果命令名为 `godot4`：

```bash
godot4 --path .
```

## 基本流程

1. 在主菜单选择“开始游戏”，命名宇宙并选择稳定纪元难度。
2. 在主界面观察资源、文明和环境状态。
3. 进入“区域 / 建筑”选择行星区域，建造设施并分配工人。
4. 进入“科技树”开始研究。研发“望远镜”后解锁 3D 星图。
5. 在“政策”界面根据环境状态调整文明运行方式。
6. 通过游戏菜单保存当前进度。

## 操作说明

### 通用

- `Esc`：游戏子界面返回；主游戏界面打开暂停菜单；暂停菜单恢复游戏
- 空格：在主游戏界面、科技树、政策、区域/建筑和 3D 星图中暂停/继续模拟
- 开发者工具打开时，`Esc` 优先关闭开发者工具
- 主界面四段滑条：在 `1x/2x/3x/5x` 间调节模拟速度，右侧显示当前倍率
- `+` / `-` 或数字键 `1/2/3/5`：快速调节倍率

### 3D 星图

- 鼠标左键拖拽：旋转视角
- 滚轮或 `W/S`：拉近/拉远
- `A/D` 或左右方向键：水平环绕
- `Q/E`：垂直俯仰
- “锁定行星”：切换行星环绕视角
- 任意天体相撞会暂停模拟并显示文明毁灭界面，可返回新游戏流程

### 科技树与区域

- 科技节点左键：开始研究；再次点击研究中节点可取消
- 科技树滚轮：缩放；右键拖拽：平移
- 区域界面 `Tab`：循环切换温度/辐射/光照热力图
- 区域界面的人口分配提供 `清空/-10/-1/+1/+10/最大（填满）`；点击 `±1` 时也可按住 `Shift` 改为 10 人，按住 `Ctrl` 直接填满或清空

## 存档位置

开发阶段统一使用项目内可见路径：

- 存档：`res://saves/`，即项目根目录的 `saves/`
- 设置：`res://settings.json`

创建宇宙后会立即写入“初始存档”；暂停菜单的“保存游戏”会打开命名面板，预填“宇宙名_Day天数”并显示最近三个存档。主菜单“加载存档”和暂停菜单“加载游戏”会打开同一浏览器，按宇宙分组列出全部存档；单击选择、双击直接加载，也可删除所选存档。

当前开发阶段不读写 `user://`。正式发布前再统一设计面向玩家的系统目录迁移策略。

## 开发者模式

1. 在“设置 → 游戏”启用开发者模式并应用。
2. 回到主界面后，可直接进入尚未研发望远镜时的星图。
3. 点击顶部“开发者工具”，可修改当前人口、库存人口、生育人口、7 类资源和 3 类科研点，也可一键填充资源或解锁全部科技。

开发者模式开关保存在 `res://settings.json`；工具内的数值修改作用于当前测试局，保存游戏时会进入该存档。

## 开发中功能

- 完整开局引导：难度与规则说明、真实区域观察、起始定居、生存岗位、知识传承、首次建设和勘探；支持完整/精简/关闭、跳过及存档恢复
- 起始区域认知、实际勘探/迁徙队、区域库存、跨区物流、前哨与聚落
- 主界面数据告警、Tooltip 与视觉打磨
- 周期自动存档与发布版存储迁移
- 字体资源、跨平台打包与导出测试
